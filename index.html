## User interface

## Agent workflow

- [Blind agent review](https://pyrolistical.github.io/token-effort/blind-agent-review.html): Get independent reviews of a commit from several agents
- [Agent drafts queue](https://pyrolistical.github.io/token-effort/agent-drafts-queue.html): Keep your agents working through a queue while you are away
- [Mirror tmux agents](https://pyrolistical.github.io/token-effort/mirror-tmux-agents.html): Control all your agents across providers from one interface on the go
